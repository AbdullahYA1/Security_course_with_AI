# ملاحظاتي — تمرين تسريب مفتاح AI

هذا موقع ملاحظات عربي صغير يشبه تطبيقًا حقيقيًا: ملاحظات أسبوعية وزر **لخّص ملاحظاتي**. النسخة الأولى تضع مفتاحًا وهميًا في JavaScript المتصفح، والنسخة الثانية تقرأ إعداد الخادم. لا يوجد اتصال بخدمة AI خارجية ولا أي مفتاح صالح للاستخدام.

## تشغيل الموقع

من هذا المجلد في PowerShell:

```powershell
python -m pip install flask
$env:DEMO_SERVER_KEY='demo_classroom_key_v2_not_real'
python app.py
```

افتح <http://127.0.0.1:5016>. استخدم رابط **عرض النسخة بعد الإصلاح** أعلى الصفحة للمقارنة؛ المحتوى والشكل نفسهما.

## عرض المدرب أمام الطلاب

1. افتح الصفحة الرئيسية كأنك تستخدم منتج ملاحظات عاديًا. اضغط **لخّص ملاحظاتي**. ستظهر فقرة تلخص الملاحظات.
2. افتح DevTools → Network واضغط الزر مرة ثانية. افتح طلب `/api/summary` وشاهد `X-Demo-Key` في Request Headers.
3. افتح Sources أو [static/notes.js](static/notes.js) وابحث عن `AI_SERVICE_KEY`. هذا الملف يُحمّل إلى كل زائر. القيمة وهمية، لكن مكانها هو نفس خطأ تسريب مفتاح حقيقي.
4. افتح `/repaired` واضغط الزر. طلب `/api/v2/summary` لا يحمل مفتاحًا؛ الخادم يقرأ `DEMO_SERVER_KEY` من بيئته ولا يرجع قيمته للمتصفح.
5. للتدريب على GitHub، ارفع **هذا المجلد فقط** إلى مستودع عام منفصل تملكه. افتح `static/notes.js` من نافذة غير مسجّل دخول. غيّر قيمته الوهمية واعمل commit جديدًا، ثم افتح History: القيمة القديمة ما زالت في أول commit.

**المعالجة لو كان المفتاح حقيقيًا:** ألغِه أو دوّره لدى مزوّد الخدمة فورًا، افحص السجلات، انقل الاستخدام إلى الخادم أو مدير أسرار، ثم نظّف الكود وتاريخ Git بالتنسيق مع الفريق. لا تستخدم مفتاحًا حقيقيًا في هذا التمرين.
